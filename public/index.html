🔐 Authentication APIs

📝
Register (OTP Flow)
Register karna hai? Name, Email aur Password daalein — OTP email pe aayega
POST /api/auth/register-request
✅
Verify Register OTP
Email pe aaya OTP yahan daalein — Account ban jaayega
POST /api/auth/verify-register-otp
⚡
Quick Register (Without OTP)
Seedha register — Bina OTP ke account banaayein
POST /api/auth/register
🔑
Login
Existing account se login karein
POST /api/auth/login
📧
Send Email OTP
Email verification ke liye OTP bhejein
POST /api/auth/send-otp
🔓
Verify Email OTP
Email pe aaya OTP verify karein
POST /api/auth/verify-otp

👤 User APIs

📋
Get Profile
Apna profile data dekhein

✏️
Update Profile
Profile mein naam, budget, language wagairah update karein
PUT /api/user/profile
🚀
Complete Onboarding
Pehli baar user ka onboarding complete karein
PUT /api/user/complete-onboarding
🔒
Change Password
Password badlein
PUT /api/user/change-password
🎡
Spin Reward Wheel
Daily reward wheel spin karein — Points jeeten!
POST /api/user/spin-wheel

Is mahine ka poora kharcha summary dekhein

Scan Bill / Receipt
